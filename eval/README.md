# 对照评测

## 目录

```
eval/
  metrics.py                纯正则/计数，不调用模型，评审可自行重算
  terms.json                术语变体表（locked + 常见其他写法）
  runs/prl2010_excerpt/     一次真实对照
    source.md               同一段原文（PRL 105, 136805 前 7 段，2183 字符）
    baseline.md             不带 Skill 的模型一次成稿
    skill.md                Skill 跑的纯中文译文
    skill_bilingual.md      Skill 跑的段落对照（段号来源）
    scorecard.md            指标表
    report.txt              metrics.py 的完整输出
```

## 复算

```bash
python eval/metrics.py eval/runs/prl2010_excerpt
```

打印指标表与逐术语明细；`--json` 输出完整结构，`--write <path>` 存成 markdown。

## 指标口径

| 指标 | 定义 | 局限 |
| --- | --- | --- |
| 术语一致率 | 该术语在译文中只出现**一种**中文写法的比例 | 只衡量"前后一致"，不衡量"译得对不对" |
| 术语变体总数 | 所有术语的不同中文写法个数之和 | 变体表是人工列的，可能漏 |
| 数字保留率 | 原文数字 token 在译文中出现的比例 | 不看语义，单位另计 |
| 引用标记保留率 | `[n]`、`[1-19]` 等在译文中原样出现的比例 | 合并/拆分引用组会判失败 |
| 图表引用本地化率 | `Fig. 3a` 是否变成「图 3a」（编号一致） | 若改写成"第三幅图"会判 0 |
| 段号可回指率 | 译文引用的段号数 / 原文段落数 | 无段号的译文恒为 0 |
| 是否标注不确定 | 是否出现「待确认/不确定/疑为」等标记 | 标记了也可能是错的 |

## 说明

- 源文本摘自 Min, Lee, Hone, Shan, Heinz, *Phys. Rev. Lett.* **105**, 136805 (2010)，仅用于可复现的对照实验，非完整转载。
- baseline 与 skill 两组由同一模型完成，唯一差别是"有无这套流程"，属于**演示协议**，样本量小（1 篇、7 段），不构成统计结论。相关讨论见 `docs/METHOD.md` 第 3.3 节与 `docs/LIMITS.md` 第 4 节。
